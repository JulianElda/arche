# stilo

> Bind them upon thy fingers, write them upon the table of thine heart.

[![npm version](https://img.shields.io/npm/v/@julianelda/stilo)](https://www.npmjs.com/package/@julianelda/stilo)

Tailwind font families for the Heliotrope typeface.

stilo sets `font-sans`, `font-serif` and `font-heading` but ships no font files:
Heliotrope is licensed from MB Type and cannot be redistributed. Load the
`@font-face` rules separately, before or after `@import "@julianelda/stilo"`;
until they load, text falls back to Georgia.
